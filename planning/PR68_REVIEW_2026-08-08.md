## Blockers (must fix before any merge path)

### P0 — Schema / mother SoT conflicts

1. **`ScholarshipProgram` / `ScholarshipProgramType`** replace mother `scholarships` / `scholarship_types`  
   - Models + migrations + seeders + `scholars.scholarship_program_id`  
   - Breaks `master` Livewire/tests that still use `App\Models\Scholarship` → CI: `Class "App\Models\Scholarship" not found`

2. **`documents` redesign incompatible with mother #35/#65**  
   - UUID PK only; **no** `file_type_id` / `stored_filename` / `mime_type` / `uploaded_by` on `documents`  
   - Mother + #65 upload path write those columns + `versions()` with `stored_filename`  
   - Blind merge would break AddFile / Edit / download / smoke

3. **`audit_logs` column rename** `record_type`/`record_id` → `loggable_type`/`loggable_id` (+ required)  
   - Breaks Notifications / auth audit writes on master  
   - CI: `NOT NULL constraint failed: audit_logs.loggable_type`

4. **Duplicate / conflicting migrations** with mother history  
   - Parallel `2026_07_20_*` scholars/documents vs mother `2026_07_15_*` + additive `2026_07_29_*`  
   - `migrate` on a fresh DB is non-deterministic / double-create risk

5. **`folders` table** as documentable parent — not in locked V1 stitch plan; needs explicit product ACK before shipping
